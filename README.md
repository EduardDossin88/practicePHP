# Импорт CSV и API поиск

Бэкенд-приложение для импорта данных из объемных CSV-файлов



## Стек технологий
* **PHP 8.5** (разделен на FPM для веба и CLI для фоновых задач)
* **PostgreSQL 15**
* **Nginx** (настроен HTTPS с самоподписанными сертификатами)
* **Docker & Docker Compose** (Multistage сборка)
* **Make** (управление через Makefile)

## Архитектурные решения
1. **Разделение FPM и CLI:** Скрипт импорта (`import.php`) выполняется в изолированном контейнере `php-cli`, чтобы не занимать воркеры Nginx/FPM и исключить падение по `max_execution_time` при обработке больших файлов. API поиска работает через легковесный `php-fpm`.
2. **Паттерн Singleton:** Подключение к БД реализовано через (`Database::getInstance()`), что гарантирует создание лишь одного соединения за время выполнения скрипта.
3. **Безопасность:** Трафик проксируется через HTTPS (порт 443).
4. **Автоматизация развертывания:** Все команды скрыты под элегантными алиасами в `Makefile`.

## Быстрый старт (Установка и запуск)

Убедитесь, что у вас установлены **Docker**, **Compose** и утилита **Make**.

**1. Сгенерируйте локальные SSL-сертификаты:**
\`
make cert
\`
*(На Windows без утилиты openssl, сертификаты можно сгенерировать через Docker: `docker run --rm -v ${PWD}/certs:/certs alpine sh -c "apk add --no-cache openssl && openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /certs/localhost.key -out /certs/localhost.crt -subj '/CN=localhost'"`)*

**2. Соберите образы:**
\`
make build
\`

**3. Поднимите контейнеры (БД, Nginx, PHP-FPM) в фоновом режиме:**
\`
make up
\`

## Импорт данных (CLI)

Для загрузки данных из файла `data.csv` в базу данных выполните команду:
\`bash
make import
\`
Команда поднимет временный контейнер `php-cli`, выполнит парсинг, загрузит данные в PostgreSQL и автоматически удалит контейнер, освободив память.

## Использование API (Поиск и фильтрация)

API доступно по защищенному протоколу HTTPS. Формат ответа — `JSON`.

**Точка входа:**
\`https://localhost/search.php\`

**Поддерживаемые GET-параметры для фильтрации:**
* `country` (строка) — фильтрация по стране
* `is_active` (boolean: true/false) — статус активности
* *(здесь можно дописать остальные параметры, если они добавлены в код код)*

**Пример запроса:**
\`bash
curl -k -X GET "https://localhost/search.php?country=USA&is_active=true"
\`

**Пример ответа:**
\`json
[
{
"id": 1,
"country": "USA",
"city": "New York",
"is_active": true,
"gender": "male",
"birth_date": "1990-05-15",
"salary": "5000.00",
"has_children": false,
"family_status": "single",
"registration_date": "2023-01-10"
}
]
\`
